# 苏州大学网课自动播放

适用于 `hike-teaching-center.polymas.com` 的用户脚本。手动打开课程后，尝试启动视频播放；当前视频正常结束后，尝试打开并播放下一节。

**[点击安装 / 更新脚本](https://raw.githubusercontent.com/Hanratty211/soochow-university-course-autoplay/main/polymas-auto-next.user.js)** · [下载发布包](https://github.com/Hanratty211/soochow-university-course-autoplay/releases) · [反馈问题](https://github.com/Hanratty211/soochow-university-course-autoplay/issues)

> 当前版本：**v1.2.1 预览版**。已通过自动化模拟测试，并根据真实详情页截图修复了跨页面续播；仍需在完整课程流程中继续验证。

## 安装：已有脚本猫或油猴

1. 在已安装脚本管理器的浏览器中，点击上方 **“点击安装 / 更新脚本”**。
2. 脚本猫或油猴弹出安装页后，确认名称为 **“苏州大学网课自动播放”**，点击 **安装**；旧版用户选择更新或覆盖。
3. 返回课程页面并刷新。右下角出现 **“视频自动续播”** 面板，说明脚本已运行。

这里的“一键安装”指从链接打开脚本管理器的安装页，仍需你在安装页确认一次。网页不能替你安装浏览器扩展。

## 第一次使用：先安装脚本管理器

以下任选一个即可：

| 扩展 | 官方安装说明 |
| --- | --- |
| ScriptCat（脚本猫） | [快速开始](https://docs.scriptcat.org/docs/use/use) |
| Tampermonkey（油猴） | [官网下载](https://www.tampermonkey.net/) |

安装扩展后，再点击本仓库的安装链接。脚本在浏览器里运行，日常使用不需要安装 Node.js、Python 或启动终端。

如果扩展提示缺少脚本执行权限，打开 Chrome 的扩展管理页面 `chrome://extensions/`，进入该扩展的详情，按扩展提示开启用户脚本权限；较旧 Chrome 可能需要开发者模式。不同版本的选项不同，参见 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209) 和 [脚本猫安装说明](https://docs.scriptcat.org/docs/use/use)。

## 安装链接只显示代码怎么办

这是浏览器或扩展没有接管安装链接时的备用办法：

1. 打开 [脚本源文件](https://raw.githubusercontent.com/Hanratty211/soochow-university-course-autoplay/main/polymas-auto-next.user.js)，全选、复制全部内容。
2. 点击浏览器工具栏的脚本猫或油猴图标，进入脚本管理界面，选择 **新建脚本 / 添加新脚本**。
3. 删除编辑器里的默认模板，粘贴代码。Mac 按 `⌘S`，Windows 按 `Ctrl+S`，也可以点保存按钮。
4. 检查脚本已启用，回到课程页面刷新。

如果访问不了 `raw.githubusercontent.com`，可从 [Releases](https://github.com/Hanratty211/soochow-university-course-autoplay/releases) 下载 `.user.js` 文件，用文本编辑器打开并按上述步骤复制。更新已有脚本时直接替换原脚本内容，避免同时启用两份。

## 怎么使用

1. 正常登录 AI 教学中心，打开课程的学习资源列表。
2. **展开后续课程所在的章节**，让目录里的视频标题可见。
3. 手动点击想观看的那一节。脚本记录当前标题和目录顺序，进入视频页后自动尝试点击中央播放按钮；找不到按钮时尝试调用 HTML5 视频播放接口。
4. 视频正常播放结束后，脚本等待平台更新状态，优先使用 **下一节 / 下一个视频** 按钮。详情页没有下一节按钮时，脚本保存当前课程，点击左上角 **返回**，再从目录打开下一条 `.mp4` 资源。
5. 下一节播放器出现后自动尝试启动。若目录明确显示锁定，等待平台正常解锁，最多 90 秒。

课程标题、目录顺序和待续播状态保存在当前标签页的会话存储中，详情页整页跳转后仍会保留。直接进入或刷新 `resource-detail` 也会尝试播放当前视频；要可靠定位下一节，仍建议从展开的目录进入。

| 面板提示或按钮 | 含义 / 操作 |
| --- | --- |
| 等待播放器并自动播放 | 已记录选课，正在等视频加载 |
| 正在播放 | 已启动当前视频 |
| 暂停续播 | 关闭后续自动启动和切换，当前视频继续播放 |
| 开启续播 | 重新开启功能；已暂停的当前视频可手动播放 |
| 点击播放 | 浏览器拒绝自动播放或启动失败，点此重试 |
| 下一节仍未解锁或未找到 | 检查课程完成状态、展开目录，或手动进入下一节 |

脚本不会反复恢复你在播放过程中手动暂停的视频。浏览器对有声自动播放的限制可能仍要求一次真实点击；脚本模拟点击不能保证替代这一授权。

## 当前限制

- **选择器尚未在真实页面验证。** 目前依据课程标题截图和常见 HTML5 播放器结构实现。
- 详情页没有“下一节”按钮时，会尝试点击文本为“返回”的按钮，再按目录顺序续播；网站若更改返回按钮文字或目录结构，需要更新选择器。
- 支持主页面及同源 iframe 中的 HTML5 `video`；跨域 iframe、Shadow DOM 和特殊播放器需要单独适配。
- 折叠章节、翻页、虚拟列表、重复课程标题或未知锁定图标可能影响目录识别。
- 会话状态只保存在当前浏览器标签页；关闭标签页后清除。课程目录折叠时，返回后可能需要手动展开对应章节。
- 如果另一个插件也负责自动播放或切课，建议只启用其中一个，避免重复操作。

## 数据与权限

脚本仅在上述教学中心域名运行，`@grant none`，无第三方运行依赖。它读取页面中的课程标题、按钮和视频状态，通过页面按钮和媒体接口操作；脚本代码没有采集 Cookie、上传课程数据或调用学习完成接口的逻辑。

正常播放仍由课程网站处理视频请求和学习记录。脚本不修改学习进度、播放速度或课程解锁状态。更新检查和更新下载由脚本管理器依据元数据中的 GitHub 地址执行。

## 排查与反馈

**页面没有控制面板：** 检查脚本是否启用、网址是否匹配、扩展是否拥有该网站的访问权限和用户脚本执行权限，然后刷新页面。

**进入页面仍不播放：** 先查看面板是否显示“点击播放”；若没有识别到播放器，反馈播放器类型及对应元素结构。中央播放按钮可通过 `CONFIG.startButtonSelector` 适配。

**播完不切换：** 查看面板提示；确认后续课程已展开、已解锁，并检查详情页是否提供下一节按钮。独立详情页缺少目录时见“当前限制”。

提交 [Issue](https://github.com/Hanratty211/soochow-university-course-autoplay/issues) 时，请提供浏览器版本、脚本管理器、脚本版本、面板提示和已隐去个人信息的截图。若能提供播放按钮、下一节按钮或课程行的 HTML，会更便于适配；不要提交账户凭据或完整登录链接。

可修改脚本顶部的 `CONFIG`：

| 配置 | 用途 |
| --- | --- |
| `nextButtonSelector` | 自定义下一节按钮选择器，默认自动识别 |
| `resourceRowSelector` | 自定义课程资源行选择器，默认按 `.mp4` 标题识别 |
| `startButtonSelector` | 自定义中央播放按钮选择器，默认包含常见播放器类名 |
| `lockedSelector` | 自定义锁定状态选择器 |
| `unlockTimeout` | 等待下一节可播放的最长时间，默认 90 秒 |
| `playerTimeout` | 等待播放器启动的最长时间，默认 30 秒 |

## 开发与测试

安装脚本的普通用户不需要执行以下命令。开发验证使用 Node.js 26 或更新版本：

```sh
git clone https://github.com/Hanratty211/soochow-university-course-autoplay.git
cd soochow-university-course-autoplay
npm ci
npm run check
npm test
```

测试使用 jsdom 模拟目录、详情页返回、跨页面状态、播放器、结束事件和浏览器播放拒绝，覆盖进入页面启动、中央按钮、延迟创建播放器、手动暂停、切课取消、重复安装及自动续播。模拟测试不能替代真实浏览器、网站状态更新和自动播放权限验证。
